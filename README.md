# 🍕 PizzaHut SQL Analysis

## 📌 Project Overview

This project focuses on analyzing PizzaHut pizza sales data using **MySQL**.

The objective is to use SQL queries to explore sales performance, customer
ordering patterns, pizza preferences, revenue generation, and category-wise
performance.

The project contains **13 SQL analysis questions**, ranging from basic
SQL queries to advanced analysis using aggregations, joins, and window
functions.
